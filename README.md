# Kuro AA Mod

为 PC 云豹版《英雄传说：黎之轨迹》提供 DLAA / DLSS、FSR 和 XeSS 抗锯齿，改善头发、栏杆、建筑边缘和远处细线的闪烁。复制文件即可使用，无需另行安装 ReShade。

## 游戏支持

目前抗锯齿规则适配了最新云豹 **1.1.0 版《黎之轨迹 I》**。

《黎之轨迹 II》云豹版暂未适配界面保护规则，可尝试全屏 AA，但兼容性尚未验证，文字也可能变糊或出现残影。预计下个版本进行适配。其它发行商版本不在当前支持范围内。

## 安装与升级

从 [Releases](https://github.com/Jeoitim/kuro-aa-mod/releases/latest) 下载 `KuroAA-0.4.0-portable.zip`，不要下载 GitHub 自动生成的源码 ZIP。

1. 退出游戏和 Mod 设置器。升级时先卸载现有版本。
2. 将包内 `GameFiles` 的内容复制到包含游戏程序的目录。一代程序为 `ed9.exe`。
3. 启动游戏，或打开 `KuroAA/KuroAA.Settings.exe` 调整设置。

遇到已有的 `dxgi.dll`、`d3d11.dll` 或 ReShade 配置时不要覆盖，先处理其它注入器的冲突。当前设置器的启动和安装脚本面向一代；二代试用需手动复制文件、选择全屏 AA，并从 Steam 启动。

本包只新增 `dxgi.dll`、`ReShade.ini` 和 `KuroAA` 文件夹。设置器、运行库、配置及许可证都在 `KuroAA` 内。

## 设置建议

退出游戏后保存设置，下次启动生效。设置器只管理本抗锯齿 Mod。

![抗锯齿设置](docs/images/settings.png)

| 设置 | 建议 |
| --- | --- |
| NVIDIA 显卡，支持 DLSS | NVIDIA DLAA / DLSS → DLAA |
| AMD 显卡 | AMD FSR → Native AA |
| Intel 显卡 | Intel XeSS → Native AA |
| 游戏内抗锯齿 | 先关闭，避免叠加后画面更软 |
| 运动估计质量 | 默认 High；帧率压力明显时可试 Balanced |
| 锐化强度 | 默认 0；需要时先试 0.03–0.08 |
| 角色界面抗锯齿（实验） | 默认关闭，开启可能卡顿 |
| 诊断采集 | 正常游玩保持关闭 |

锐化支持 **0.00–1.00**，步长 0.01。推荐范围不是限制，过高容易出现亮边和细线闪烁；锐化不能消除鬼影或降低操作延迟。运动估计质量影响三个后端的运动信息，与性能档位中的 Balanced 不是同一选项。

DLSS 的原生分辨率档位叫 DLAA，FSR / XeSS 叫 Native AA。Quality、Balanced、Performance、Ultra Performance 等档位重建已经渲染好的画面，不保证提高帧率。本包不提供帧生成。

选择这些档位不需要手动降低游戏分辨率，通常保持屏幕原生分辨率即可。本 Mod 在游戏完成渲染后缩小颜色图，再重建回当前处理目标的尺寸；它不会让游戏像原生 DLSS / FSR 集成那样直接少渲染像素。

本 Mod 不限于 1080p。主场景按实际纹理尺寸处理，普通分辨率切换会重置历史与角色缓存。1440p / 4K 会增加处理和显存开销，尚未逐一完成游戏验收。角色实验功能的缓存像素预算不是主场景分辨率上限；超出缓存预算的模型保持原画面。详见 [分辨率与档位](docs/resolution.md)。

### 抗锯齿规则

三种规则是平行选项，一次选择一种。默认使用引擎边界，切换规则不会更换厂商算法。

| 规则 | 处理方式与注意事项 |
| --- | --- |
| 引擎边界 | 在游戏绘制界面前处理场景，尽量保持文字清晰；无法确认边界时跳过处理 |
| Shader 签名 | 在识别到界面着色器前处理场景，同样用于保护文字；部分界面可能无法识别 |
| 全屏 AA | 处理最终画面，场景和界面都参与重建；覆盖更直接，但文字可能模糊、变形或残影 |

全屏 AA 不等于关闭抗锯齿。关闭效果请在算法列表中选择“关闭”。详见 [规则说明](docs/aa-rules.md)。

### 角色界面抗锯齿（实验）

使用引擎边界或 Shader 签名时，装备 / 换装页的独立角色模型**默认不由本 Mod 做抗锯齿处理**。勾选此项后，模型单独使用所选厂商算法，文字仍保持独立。全屏 AA 已处理整个画面，不再叠加这项功能。

开启后进入面板、切换角色可能明显卡顿，停顿后 AA 才生效，也会增加 GPU 和显存开销。已加入上下文复用来减少重复初始化，但未确认游戏中的卡顿完全消失，建议保持关闭。[详细说明](docs/vendor-preview.md)

## 画质与性能限制

运动信息由 AeonSR 光流估算，不是游戏原生集成。移动物体、透明特效和快速转动镜头仍可能残影，画面也可能偏软。采样抖动保持关闭，避免已观察到的镜头抖动。

鬼影明显时可保持 DLAA / Native AA 和 High，逐个比较后端。完整战斗界面、HDR、MSAA 与输入延迟尚未全部验证。RTX 3060 Laptop、1080p 是作者测试环境，不是推荐设备或最低配置。

## 关闭与卸载

退出游戏后，设置器可关闭效果，或用“关闭注入”停止加载整个 Mod。

手动安装时，对照便携包删除 `dxgi.dll`、`ReShade.ini` 和 `KuroAA` 文件夹。关闭注入后，注入文件名为 `dxgi.dll.kuro-disabled`，删除它即可。只删除本包新增文件，不动游戏、存档或其它 Mod。游戏根目录的 `ReShade.log` 也可在退出后删除。

脚本安装会记录新增文件，可按记录卸载：

```powershell
./tools/Install.ps1 -GameDirectory "<游戏目录>" -PackageDirectory "<解压目录>/GameFiles"
./tools/Uninstall.ps1 -GameDirectory "<游戏目录>"
```

脚本保留游戏、存档及运行日志；改动过的二进制不会直接删除。
