# 验证记录

## 环境与范围

当前规则适配最新云豹 1.1.0 版《黎之轨迹 I》。作者测试环境为 RTX 3060 Laptop GPU、驱动 610.88、1080p，不是推荐硬件或最低配置。

实际游戏确认 DLAA 可运行，关闭采样抖动后镜头稳定。场景与界面分开处理后收到“文字明显改善，场景正常”的反馈。角色界面实验功能可处理独立模型，但进入面板和切换角色有明显卡顿，因此默认关闭。

《黎之轨迹 II》云豹版尚未完成规则适配或游戏验证，全屏 AA 仅作为可尝试路径。

## 构建与安装

- MSVC 编译 KuroUI、AeonSR 扩展及 DX11 夹具，C# 编译中文设置器。
- 设置器自测覆盖厂商档位、锐化 0–1、深色控件与完整边框。
- 三种规则配置互斥，切换后端不改变规则，角色界面实验功能默认关闭。
- 22 文件安装 / 卸载、重复安装拒绝、冲突拒绝与安装记录路径逃逸拒绝，游戏程序哈希不变。
- DLAA、FSR、XeSS 的运行与界面隔离检查通过，不需要额外安装 ReShade 软件。

## 规则检查

| 路径 | UI 不同像素 | 场景不同像素 |
| --- | --- | --- |
| 引擎边界，场景 640 → 输出 800 | 0 | 41469 |
| Shader 签名，场景 640 → 输出 640 | 0 | 41388 |
| 全屏 AA | 21882 | 43615 |
| Shader 未匹配 | 0 | 0 |

全屏 AA 改变 UI 是该模式的预期风险，不能称为界面保护通过。不同像素表示画面发生变化，不是质量排名。

引擎夹具还覆盖错误函数指纹、UI 先提交、纯 UI、入口禁用和辅助 UI 目标。无法确认场景时保留原画面；正向用例处理场景而不改变已隔离的文字区域。

## 角色界面检查

三种厂商后端分别在引擎边界和 Shader 签名下运行 420 帧，每组替换模型纹理三次。六组均确认三次上下文复用，UI 与原始 alpha 不同像素均为 0。

XeSS 初始化增加互斥，解决双视图并发初始化时在运行库内崩溃的问题。厂商历史与主场景分开，资源更换后重置历史，结果回写时恢复原始透明度。

这些检查证明处理时序、状态恢复与复用路径，不代表真实游戏首次进入或切角色已无卡顿，也不保证所有预览页面都被识别。

## 尚未完成

0.4.1 自动检查通过管理器单档位映射、安装卸载、升级备份与偏好保留、三厂商场景 / UI 隔离和六组角色 AA。界面区域及角色原始 alpha 的不同像素均为 0。旧配置 `UpscaleMode=4` 仍只创建 640×360 → 640×360 的原生 AA 特性。编译缓存也通过首次编译、跨进程命中和损坏后回退检查。

这些是独立夹具结果，不是新增的游戏帧率或动态画质验收。实验实现和踩坑记录保存在 `codex/scene-scale-experiments`，未删除。

完整战斗布局、快速运动鬼影、透明粒子、全部 UI、HDR、MSAA、输入延迟与其它显卡的兼容性仍需继续验证。

目前没有可靠的游戏原生运动矢量、相机矩阵、投影抖动或完整 reactive mask，效果不能等同官方原生集成。
