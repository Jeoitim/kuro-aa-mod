# 0.3.1 验证

## UI 隔离验证版

本地 scene-engine-adaptation 分支增加了引擎调用层路径，正式 0.3.1 release 保持不变。
PE 构建信息与运行时代码指纹先校验，再识别首批 UI；支持场景颜色与窗口尺寸不同。
在 UI 开始前处理缓存的场景颜色，UI 开始后封闭本帧 AA。设置器移除全屏回退开关。

MSVC / C# 编译与设置器、安装卸载测试已通过。Engine.Tests.ps1 自动覆盖三后端、
错误函数指纹、UI 先提交、纯 UI、入口禁用，以及辅助 UI 目标与跨目标 UI 先提交。
九项自动回归全部通过：三个厂商后端处理了场景，UI 区域不同像素均为 0；
UI 先提交、跨目标 UI 先提交、纯 UI、入口禁用与错误指纹的场景 / UI 差异均为 0。
先提交辅助 UI 的正向用例成功处理缓存主场景，主 UI 区域仍不同像素为 0。

本机游戏已安装并运行验证版，日志记录 engine frames=3242、UI-before-scene bypass=605，
证明入口和保护分支实际执行。当前一次运行的 engine GPU total 约 5.66–6.17 ms，
不是输入延迟或受控 A/B 性能结果；游戏文字观感尚待用户反馈。
独立角色预览的 AA 覆盖和全部游戏 UI 画质仍未验收。
