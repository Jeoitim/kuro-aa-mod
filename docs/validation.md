# 0.3.1 验证

## 范围

测试设备为作者的 RTX 3060 Laptop GPU，驱动 610.88；游戏为云豹版 DX11 build 16257982。
这是测试环境，不是推荐硬件。实际游戏已确认 DLAA 运行、关闭抖动后镜头稳定，
场景模式收到“文字明显改善，场景正常”的反馈。

0.3.1 使用集中式 KuroAA 目录、三种厂商后端和中文设置器。

## 已通过

- MSVC 编译场景组件与 DX11 fixture，.NET Framework x64 编译设置器。
- 设置器自测、算法 / 档位映射、锐化 0–1 范围、开启 / 停用注入。
- 22 文件安装与卸载、重复安装拒绝、目录冲突拒绝、receipt 路径逃逸拒绝，游戏程序哈希不变。
- Runtime.fx 在 1080p / 1440p 的 DXBC 编译无错误或警告；technique 默认禁用。
- DLAA、FSR、XeSS 各 1200 帧 GPU 运行，正常退出、输出非空、运行库 ready。
- 集中目录中的 add-on、运行库与配置查找均正常，不依赖额外 ReShade 安装。

600 帧场景 / UI 回归：

| 路径 | UI 不同像素 | 场景不同像素 |
| --- | --- | --- |
| DLAA | 0 | 47325 |
| FSR Native AA | 0 | 48631 |
| XeSS Native AA | 0 | 48798 |
| DLAA 离屏目标 | 0 | 47129 |
| 未识别节点 | 0 | 0，整帧 BMP 与基线哈希一致 |

这些结果验证运行与插入时序，不是抗锯齿质量评分，也不替代真实游戏动态验收。
中文深色设置器的内容布局已检查，锐化数字框居中，厂商术语保持与运行库一致。
下拉框本体采用单次双缓冲绘制，弹出列表背景由控件统一绘制；自测验证三个下拉列表
在背景擦除时实际写入深色而不是系统白色。实际交互仍应在前台检查。
