# Kuro AA Mod 0.4.0

支持最新云豹 1.1.0 版《黎之轨迹 I》，提供 DLAA / DLSS、FSR 和 XeSS。

- 引擎边界、Shader 签名和全屏 AA 作为平行选项，按界面保护与覆盖范围选择。
- 增加“角色界面抗锯齿（实验）”，默认关闭。装备 / 换装模型默认不单独处理，开启后可能卡顿。
- 独立角色视图使用厂商重建，保留透明度；同尺寸上下文可复用，减少切角色时重复初始化。
- 修正锐化滑条焦点边框和数值框底边，整理用户说明与路线图。

## 安装

下载 `KuroAA-0.4.0-portable.zip`。退出游戏，先卸载已有版本，再将 `GameFiles` 内容复制到含 `ed9.exe` 的目录。无需安装 ReShade 软件，设置器位于 `KuroAA/KuroAA.Settings.exe`。

游戏内 AA 建议先关闭。默认 High 运动估计、锐化 0；锐化可填 0–1，需要时先试 0.03–0.08。

## 注意事项

移动物体和透明特效仍可能残影，效果不等同游戏原生集成。角色界面实验功能可能在进入面板和切角色时明显卡顿，建议保持关闭。

《黎之轨迹 II》云豹版暂没有界面保护规则，可手动试用全屏 AA，但兼容性未验证，文字也可能模糊。当前设置器的启动与安装脚本面向一代；二代请从 Steam 启动。

下个版本计划适配二代，后续在设置器中增加游戏版本选择与对应注入。这些是路线图，0.4.0 尚未提供。

已通过 MSVC / C# 编译、设置器自测、安装卸载以及三厂商后端在两种界面保护规则下的独立视图检查。完整战斗布局、HDR、MSAA 和输入延迟仍未全部验收。
