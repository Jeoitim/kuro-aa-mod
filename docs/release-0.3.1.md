# Kuro AA Mod 0.3.1

支持 PC 云豹版《英雄传说：黎之轨迹》的 DLAA / DLSS、FSR 和 XeSS。

- 安装内容整理为 `dxgi.dll`、`ReShade.ini` 和 `KuroAA` 文件夹，便于对照卸载。
- 中文深色设置器精简选项，锐化数字居中，修正下拉框深浅背景交替绘制。
- 默认 Native AA、High 运动估计、锐化 0，场景处理开启。
- 固定版本的运行库、许可和校验值加入源码仓库，方便后续开发。
- 更新安装、设置、卸载说明与验证记录。

## 安装与升级

下载 `KuroAA-0.3.1-portable.zip`。退出游戏，先卸载现有版本，再将 `GameFiles` 的内容复制到含 `ed9.exe` 的目录。
不要覆盖其它注入器的同名文件。中文设置器位于 `KuroAA/KuroAA.Settings.exe`。

游戏内 AA 建议先关闭。运动估计默认 High；帧率压力明显时可试 Balanced。锐化支持 0–1，推荐需要时先试 0.03–0.08。

## 验证与限制

MSVC / C# 编译、设置器自测、安装卸载和三个厂商后端各 1200 帧运行检查均通过。
场景/UI、离屏目标与未知节点回归通过，UI 区域与无 Mod 基线一致。

适配验证于云豹 1.1.0 版《黎之轨迹 I》，未覆盖全部 HUD、战斗、HDR 或 MSAA。
运动由光流估算，不是游戏原生集成；透明特效和移动物体仍可能出现残影。
RTX 3060 Laptop 是作者的测试设备，不是推荐硬件或最低配置。
