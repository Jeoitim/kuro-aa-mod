# 装备 / 换装角色预览定位结果

本次实际页面采样确认：角色几何经 OffScreenRenderer 调用链绘制到一张 1920x1080、RGBA8 的颜色纹理。
后续 UI draw 75 从像素 shader 的 s0 读取这张纹理，合成到另一张页面目标。
首批 UI 在更早的 draw 37 / 48 已开始。

当前引擎规则缓存的最近同尺寸 SDR 目标可能是页面背景 / 后处理目标，而不是模型纹理。
因此仅靠“主场景尺寸相同”和“首批 UI 前处理”不能确保模型得到 AA。
全屏规则改善模型锯齿，与这条独立纹理后续合成路径相符。

## 后续厂商预览实验

已增加基于资源关联的模型输入识别，在它混入文字之前处理。
定制 AeonSR 提供独立预览接口，可与主场景在同一帧处理各自纹理，不共用时域历史。

预览回写增加原始 alpha 恢复，自动化夹具检查透明度逐像素不变。
资源销毁、帧间断和档位改变会重置 / 释放历史。上游普通颜色合成不能直接保证 alpha 不变，
因此这个保护步骤由 KuroUI 单独执行。

该实现仍为实验功能，真实装备页的动态画质与性能待用户验收。
测试通过只证明厂商处理、状态恢复和 UI 隔离，不代表角色预览全部锯齿已经解决。
实现与限制见 [厂商预览](vendor-preview.md)。
