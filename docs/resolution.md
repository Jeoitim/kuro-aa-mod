# 分辨率

通常保持屏幕原生分辨率即可。0.4.1 只有 DLAA / Native AA，输入、输出与当前处理目标尺寸一致，不调整游戏的场景倍率。

主场景读取实际颜色纹理尺寸，1080p 是作者的测试环境，不是硬编码限制。场景目标与窗口尺寸可能不同，界面保护规则在确认目标后处理。1440p、4K 和全部宽屏布局尚未完成游戏验收，不能只凭代码支持实际尺寸就认定画质与性能都已通过。

更高分辨率会增加 AA 处理和显存开销。角色缓存采用可调的估算预算与数量上限，还可查询可用显存；这只约束额外角色视图，不限制主场景的输出分辨率。超出预算的模型保持原画面。

普通窗口或游戏输出分辨率切换会释放旧角色上下文，并为新尺寸重新准备资源。切换和首次准备时可能短暂停顿。相同尺寸的闲置上下文可以复用，画面历史则必须重置。

编译结果可以保存到磁盘，上次进程中的显卡上下文、纹理句柄和画面历史不能直接恢复。缓存与预热减少部分编译工作，不保证下次启动完全无停顿。详见 [缓存设置](cache-settings.md)。
