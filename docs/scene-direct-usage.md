# DLSS 场景直连试用版

此版本尝试让游戏先渲染低分辨率场景，再由 DLSS 重建到输出尺寸，最后绘制原分辨率界面。它省去了颜色先放大后再次 AA 的重复处理，但仍有少量尺寸常量修补、共享资源复制和同步。不能预先保证提速。

关闭游戏后，在管理器选择 NVIDIA DLAA / DLSS 和所需档位，再启动游戏。质量、均衡、性能、超级性能进入直连路径；DLAA 使用原生分辨率。试用安装默认选择均衡，其它原有偏好保留。直连暂不附加锐化处理。

比较时使用同一存档、镜头和帧率限制，观察颜色、HUD 文字、移动稳定性以及帧时间 / FPS。先用均衡，再退出游戏切到 DLAA；无需反复切界面或截图。采集结束后再比较稳定帧率，避免把启动时的准备开销当作持续性能。

一次运行会在跳过 60 次场景调用后采集 120 次分段数据，保存为 `KuroAA/KuroUI-scale-timing.csv`。`KuroAA/AeonSR.log` 中的 `scene-direct` 行显示实际输入 / 输出尺寸，`scene-direct-perf` 行显示运动估计和 DLSS 的 GPU 时间。若看到 `direct DLSS preparation unavailable` 或倍率回退日志，该次运行没有完成直连，不能用它评价直连性能。

出现异常时先退出游戏，选回 DLAA。完整回滚组件位于游戏目录的 `.kuro-aa-backups/scene-direct-*`：退出游戏后将其中两个 addon、管理器和两份 ini 恢复到 `KuroAA`。请保留备份，不需要覆盖运行库或删除缓存。

已通过真实 GPU 夹具的尺寸、颜色、UI 像素和状态恢复检查；实际游戏的画面和性能仍需验证。调查与限制见 [调查记录](render-scale-investigation.md)。
