# Kuro AA Mod 0.4.1

支持云豹 1.1.0 版《黎之轨迹 I》，提供 NVIDIA DLAA、AMD FSR Native AA 和 Intel XeSS Native AA。

- 只保留 DLAA / Native AA，保持游戏渲染尺寸。管理器移除质量、均衡、性能等非原生档位，旧配置也会归一化为原生模式。
- 增加角色缓存预算、数量上限和可用显存保护。复用已准备好的角色 AA 上下文，减少进入面板、切换角色时的重复初始化；缓存满后可选择跳过 AA 或排队准备。
- 支持保存着色器编译缓存和启动预热。复用已有编译结果，并把部分准备工作提前到加载阶段，减少抗锯齿启动时的重复编译和集中等待。
- 整理设置器和用户说明，保留引擎边界、Shader 签名、全屏 AA，以及默认关闭的角色界面抗锯齿。降倍率实验和踩坑记录保存到独立实验分支，不随正式包分发。

## 安装

从本页下载 `KuroAA-0.4.1-portable.zip`，不要下载 GitHub 自动生成的源码 ZIP。

1. 退出游戏和 Mod 设置器。升级前备份现有设置，卸载旧版本。
2. 解压便携包，将 `GameFiles` 文件夹里的内容复制到含 `ed9.exe` 的游戏目录，不要把 `GameFiles` 文件夹本身放进去。
3. 确认游戏目录内有 `dxgi.dll`、`ReShade.ini` 和 `KuroAA` 文件夹，然后启动游戏。
4. 需要调整设置时，退出游戏并打开 `KuroAA/KuroAA.Settings.exe`，保存后下次启动生效。

无需另行安装 ReShade。遇到已有的 `dxgi.dll`、`d3d11.dll` 或 ReShade 配置时不要直接覆盖，先处理其它注入器的冲突。不要覆盖游戏程序或存档。

游戏内 AA 建议先关闭。默认原生 AA、高运动估计、锐化 0；锐化可填 0–1，需要时先试 0.03–0.08。详细安装、卸载和设置说明见 [README](https://github.com/Jeoitim/kuro-aa-mod#安装与升级)。

## 注意事项

本版只使用厂商的原生分辨率抗锯齿技术。升采样的稳定接入受技术限制，暂未实现可发布版本。

此前质量、均衡、性能等档位没有表现出稳定的帧率收益，还可能损失画面细节。已经尝试真正的低分辨率场景方案，但引擎适配和额外处理开销仍未解决，因此正式版删除这些档位，只保留原生 AA。实验代码、失败对照和踩坑记录继续保存在实验分支。

运动信息由光流估算，效果不等同游戏原生集成。移动物体、快速转动镜头和透明特效仍可能残影。Mod 会增加 GPU 与显存开销，不承诺帧率提升。

角色界面抗锯齿可能在进入面板和切换角色时明显卡顿，建议保持关闭。缓存和预热减少部分重复准备工作；完全首次运行、未缓存的新尺寸或厂商实例仍需初始化，不能保证完全无停顿。

《黎之轨迹 II》云豹版暂没有界面保护规则，可手动尝试全屏 AA，但兼容性未验证，文字也可能模糊。当前设置器的启动与安装脚本面向一代；二代请从 Steam 启动。

后续计划适配二代的界面保护，并继续优化角色处理的初始化开销。这些是计划，0.4.1 尚未提供二代适配。

完整战斗布局、HDR、MSAA 和输入延迟仍未全部验收。RTX 3060 Laptop、1080p 只是作者测试环境，不是推荐硬件或最低配置。
