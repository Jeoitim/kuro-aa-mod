# 抗锯齿规则

引擎边界、Shader 签名和全屏 AA 是三种平行选项。一次选择一种，保存后重启游戏生效；切换规则不会更换 DLAA、FSR 或 XeSS 后端。

目前界面保护规则适配最新云豹 1.1.0 版《黎之轨迹 I》。《黎之轨迹 II》云豹版没有对应规则，可尝试全屏 AA，但尚未验证兼容性。

## 引擎边界

通过已确认的游戏界面绘制入口，在第一批界面开始前处理已完成的场景，再让游戏继续绘制文字和面板。这是默认选项。

无法确认入口或场景目标时保留原画面，不会自动改成全屏处理。它不是分析截图里的文字，也不保证识别全部战斗与特殊界面。

## Shader 签名

通过界面着色器的指纹识别处理时机，在匹配的界面绘制之前处理场景。

签名不是“不做 AA 的着色器名单”。命中签名意味着先处理场景，随后才绘制该界面。某些文字可能更早出现，或使用不同的着色器组合，因此保护范围取决于实际界面。

## 全屏 AA

处理游戏最终画面，场景与界面一起参与运动估计、时域抗锯齿和锐化。独立角色模型也会进入处理，但文字可能变软、变形或留下残影。

适合对比效果，或试用尚无界面保护规则的游戏。它不是关闭抗锯齿；关闭效果请在算法列表选择“关闭”。

## 角色界面

引擎边界和 Shader 签名默认不处理装备 / 换装页的独立角色模型。开启“角色界面抗锯齿（实验）”后，模型单独使用所选厂商算法，再合成到界面。

该功能默认关闭。进入面板和切换角色可能卡顿，也会增加显存与 GPU 开销。全屏 AA 不叠加该功能。详见 [角色界面抗锯齿](vendor-preview.md)。

## 开发对应关系

| 规则 | 配置值 | 触发位置 |
| --- | --- | --- |
| 引擎边界 | `AARule=engine` | 经校验的游戏 UI 提交前 |
| Shader 签名 | `AARule=shader` | 匹配的 UI shader draw 前 |
| 全屏 AA | `AARule=full` | 最终画面回调 |

显式 `AARule` 决定实际路径，切换时清除另一规则的入口参数。引擎入口与签名仍须按游戏版本维护；它们不能自动理解全部 C++ 类型或所有 3D 视图。
